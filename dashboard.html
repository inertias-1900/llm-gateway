已有 key
「显示 / 复制」需要登录；普通用户只能操作自己的 key。key 值不会随统计快照下发，需要时才单独取。
「上游组」＝ 这个 key 绑定哪些组（不绑＝不限制）。绑了之后，它拉 /v1/models 只看到这些组里的模型，请求组外模型直接 403 model_not_allowed（单模型探活 404）；适合把同一台网关按订阅分组出租/隔离。
「可用模型」＝ 在（绑定的组 ∪ 全部）范围内再挑具体模型（默认全部）。限定后同样 403/404。
新建 key
留空＝用供应商自己配的 UA。这个 key 的会话 ID 会自动生成并与 key 绑定（供应商里写 __SESSION__ 时解析成它）。
普通用户新建的 key 自动限定在自己加入的上游组内；管理员新建默认可用全部模型，之后可在表格里点「可用模型」限制。
面板用户
普通用户只能看到：概览（仅自己加入的组 + 自己 key 的用量）、自己的 key、自己加入/可加入的上游组。账号只能由管理员创建。
